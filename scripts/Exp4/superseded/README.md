# Superseded Experiment 4 scripts

Development versions v1–v5 of the Experiment 4 preflight and runner, kept unmodified for transparency. They are not needed to reproduce the reported results.

The reported Experiment 4 uses `scripts/Exp4/preflight_candidate_gate_v6.py` and `scripts/Exp4/run_formal_exp4_v6.py`.

Their hard-coded output paths refer to the original locations, before the outputs were moved to `benchmark_results/Exp4/superseded/`. See that folder's README and `docs/EXPERIMENT_LOG.md` for what each version changed and why.
